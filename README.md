# SkillEntrix_movie-recomadation_system
# 🎬 Movie Recommendation System

An AI-powered Movie Recommendation System built using Python and Machine Learning techniques.  
This project recommends movies based on similarity between movie genres using Content-Based Filtering.

---

# 🚀 Features

- Movie recommendations based on user input
- Content-Based Filtering
- Cosine Similarity Algorithm
- TF-IDF Vectorization
- Uses MovieLens Dataset
- Beginner-friendly AI/ML project

---

# 🧠 Technologies Used

- Python
- Pandas
- Scikit-learn
- TF-IDF Vectorizer
- Cosine Similarity

---

# 📂 Dataset

Dataset used: MovieLens Dataset

Download here:  
https://grouplens.org/datasets/movielens/

---

# 📌 Project Workflow

1. Load Movie Dataset
2. Preprocess Movie Genres
3. Convert Text to Numerical Vectors using TF-IDF
4. Calculate Similarity using Cosine Similarity
5. Recommend Similar Movies

# 📖 Machine Learning Concepts Used

## Content-Based Filtering
Recommends movies similar to the selected movie.

## TF-IDF Vectorization
Converts movie genres into numerical vectors.

## Cosine Similarity

Measures similarity between movies.

\[
\cos(\theta)=\frac{A\cdot B}{||A||||B||}
\]
